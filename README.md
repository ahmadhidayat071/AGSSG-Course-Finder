# AGSSG Course Finder

Complete 7-file GitHub Pages / PWA package.

Files:
- index.html — main app
- manifest.json — PWA metadata
- sw.js — service worker
- icon-180.png — app icon
- icon-512.png — app icon
- prime-golf-logo.png — Prime Golf image
- README.md — project notes

Features:
- Default date = today's local date
- Search by club
- Club dropdown
- State filtering
- AM / PM
- Player count
- Cheapest AGSSG rate and savings
- Requirements
- Caddy shown only when mandatory
- Prime Golf page and WhatsApp catalogue
