# AGSSG Course Finder

Files:
- index.html — main app
- manifest.json — PWA metadata
- sw.js — offline caching/service worker
- icon-180.png — app icon
- icon-512.png — app icon
- README.md — setup notes
- prime-golf-logo.png — Prime Golf business-page logo

## Features
- Course search by state and club
- Date / AM-PM / player count
- Cheapest AGSSG rate and savings
- Booking requirements
- Caddy price shown only when compulsory
- Prime Golf business page with WhatsApp catalogue
