# AGSSG Course Finder

Files:
- index.html — main app
- manifest.json — iPhone/PWA app metadata
- sw.js — offline caching/service worker
- icon-180.png — app icon
- icon-512.png — app icon
- README.md — setup notes

## GitHub Pages
1. Upload all six files to the root of your GitHub repository.
2. Open Settings → Pages.
3. Deploy from the main branch / root folder.
4. Open the published URL on iPhone.
5. Use Share → Add to Home Screen.

The app is named **AGSSG Course Finder**.
